德味水印 本地 · 离线

给照片加一条德味水印

单文件工具，安卓有 App、电脑有网页版。自动读 EXIF，六种版式，完全离线，照片不出本机。

在线试用（不用下载） 下载安卓 App 查看源码

安卓包在蓝奏云，提取码 cqsh（不用注册、不收费）。
GitHub 打不开时用蓝奏云；想核对源码就走 GitHub。

为什么可以放心下载

  • 代码是公开的：仓库里能看到每一次提交，MIT 许可，随便审
  • 没有网络权限：App 只申请「写入相册」一项，没有联网能力，物理上不可能上传你的照片
  • 先试后下：网页版功能完全一样，点上面「在线试用」就能验证，不用先装东西
  • 不需要任何身份：无登录、无手机号、无邮箱、无内购、无广告
  • 可以校验文件：下面给了 SHA-256，下载后比对一下就知道有没有被改过
  • 作者可查：所有开发过程都在 GitHub 上，有问题直接开 Issue 找我

它是怎么工作的

  • 照片在你的浏览器 / App 里解码，画上水印，再存回本地
  • 整个过程没有任何网络请求——断网照样能用
  • 预设和图标存在本机，不上传、不同步
  • 网页版关闭页面后内存即释放
